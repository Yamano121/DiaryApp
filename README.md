# DiaryApp

DiaryApp — это личный дневник для компьютера. Вы открываете окно, видите 2 разделов слева, кликаете — и записываете туда свою жизнь: как прошёл день, какие привычки выполнили, что заметили, о чём не забыть. Всё сохраняется на вашем компьютере, никуда в интернет не уходит.

Минимальный MVP:

1. Дневник дня
   - Тайм - лайны (Например: 17:00 - 20:00: Работа);
   - Цели;
   - Указывание пользователем показателей дня: 
	   - Качество сна (0-10);
	   - Колличесво сна (указывается пользователем);
	   - Уровень энергии (0-10);
	   - Продуктивность (0-10);
	   - Оценка дня (0-10).
   - Итоги дня: Рефлексия (Несколько предложений о прошедшем дне), Одно предложение дня (1-2 предложения);
   - Привычки (Пользователь вписывает привычки, которые обязан выполнять в течении дня, например читать минимум 30 страниц в день.);

2. Заметки
   - Создавать заметки
   - Складывать их в папки
   - Помечать их степень важности, тематику. 

3. Финансы
   - Создать трату (Сколько потрачено, где потрачено, зачем потрачено, во сколько потрачено)
   - Посмотреть графики трат (Среднее количесво трат за день, неделю, месяц.)
   - Создать счет (В который пользователь может откладывать сумму, которую можно как сохранить как и вычти)

4. Спорт
   - Создать тренировку (Тип тренировки, время тренировки, дата тренеровки)
   - Указании качества, самочуствия после тренеровки

   
5. Дешборд (Главное меню)
   Вывод всех показателей и графиков:
   - Дневника
   - Заметок
   - Финансов
   - Спорта
